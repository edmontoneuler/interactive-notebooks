# Interactive Notebooks

A collection of Jupyter notebooks that use interactive Python widgets to help teach physics concepts that are not efficiently represented by static figures. 

The combination of Github Pages, jupyterlite, and Pyodide means that students do not need to download anything themselves. A minimal Python engine is spun up in their browser when they click the link. 

[CLICK HERE](https://edmontoneuler.github.io/interactive-notebooks)
