# Interactive Notebooks

A collection of Jupyter notebooks that use interactive Python widgets to help teach physics concepts that are not efficiently represented by static figures. 

The combination of Github Pages, jupyterlite and Pyodide means that students do not need to download anything themselves. Everything runs in-browser.
